# 🍳 Recipe Finder PRO

A modern recipe finder application built with **HTML**, **CSS**, and **Vanilla JavaScript**.

Users can search for recipes, browse meal suggestions, and view detailed cooking instructions through an interactive modal interface.

---

## ✨ Features

* 🔍 Search recipes by name
* 🍽️ Browse meals from TheMealDB API
* 📊 Display total number of recipes found
* 🖼️ View recipe images and categories
* 📖 Open detailed recipe instructions in a modal
* ▶️ Watch cooking tutorials via YouTube links
* ⏳ Loading state while fetching data
* ⚠️ Error handling for failed searches
* 📱 Responsive design for mobile and desktop

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6+)
* TheMealDB API
